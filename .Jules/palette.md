## 2024-05-18 - Accessible Stateful Icon Toggles
**Learning:** Stateful icon-only buttons (like password visibility toggles) are inaccessible to screen readers unless their ARIA labels and titles dynamically update to reflect the current state (e.g., from "Show password" to "Hide password") via their JavaScript event handlers, alongside ensuring the inner icon is hidden from parsing (`aria-hidden="true"`). Adding a `title` attribute provides visual tooltips on hover for non-screen reader users, which is a significant quality of life improvement.
**Action:** When evaluating icon-only buttons for accessibility, always trace their JavaScript handlers to ensure attributes are dynamically toggled. Add both `aria-label` and `title` to cover both screen reader and visual users.
