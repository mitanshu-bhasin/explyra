## 2026-08-10 - Dynamic ARIA labels for stateful icons\n**Learning:** When adding ARIA labels to stateful icon-only buttons (like password visibility toggles), setting a static label in HTML is insufficient. The `aria-label` and `title` must be dynamically updated via JavaScript to accurately reflect the resulting action of the current state (e.g., changing from "Show password" to "Hide password").\n**Action:** Always verify if an icon-only button is a toggle or stateful element. If it is, update the associated JS handler to toggle the `aria-label` and `title` attributes alongside the visual class changes.
