## 2024-06-07 - Dynamic ARIA Labels on Stateful Icons\n**Learning:** When using stateful icon-only toggle buttons (like password visibility), it's not enough to just add an initial ARIA label. The JavaScript handler must dynamically update the `aria-label` and `title` attributes to accurately reflect the current action/state (e.g., 'Show password' vs. 'Hide password') for screen readers.\n**Action:** Always verify the JavaScript handlers for stateful UI elements and ensure they update ARIA attributes in sync with visual state changes.
