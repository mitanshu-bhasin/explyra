## 2024-05-14 - Stateful Toggle Buttons Accessibility Pattern
**Learning:** For stateful icon-only toggle buttons (like password visibility), simply adding `aria-label` once isn't enough. The `aria-label` and `title` attributes must be dynamically updated via JavaScript to accurately reflect the current action/state (e.g., 'Show password' vs. 'Hide password') when the state changes. Additionally, the purely decorative inner icon elements (like FontAwesome `<i>` tags) must have `aria-hidden="true"` so screen readers ignore them and only read the button's descriptive label.
**Action:** When implementing or updating stateful toggles (like play/pause, show/hide, mute/unmute), ensure the JavaScript handler toggles both the visual state (icons) AND the semantic state (`aria-label`, `title`). Always add `aria-hidden="true"` to the decorative icon elements inside these buttons.
