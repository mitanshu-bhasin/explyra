## 2024-08-21 - Accessible Password Toggles\n**Learning:** When making stateful icon-only buttons (like password visibility toggles) accessible, static ARIA labels are insufficient; the `aria-label` and `title` attributes must be dynamically updated in JavaScript to reflect the current state (e.g., 'Show password' vs 'Hide password') to ensure accurate screen reader announcements.\n**Action:** Always verify that JavaScript handlers associated with stateful toggle buttons update their accessibility attributes in sync with visual icon changes.
