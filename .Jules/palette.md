## 2025-03-01 - Dynamic ARIA Labels for Stateful Icon-Only Toggles
**Learning:** For stateful icon-only toggle buttons (such as a password visibility toggle), setting a static `aria-label` or `title` is insufficient and actively harms accessibility. Screen readers rely on the `aria-label` to announce the button's action, and if it only ever says "Show password" even when the password is currently shown, it creates confusion.
**Action:** Always ensure the associated JavaScript handler dynamically updates the `aria-label` and `title` attributes to accurately reflect the action that will happen when the button is clicked next (e.g., swapping between 'Show password' and 'Hide password'). Additionally, ensure the inner `<i>` icon has `aria-hidden="true"` so its generic classes aren't announced.
