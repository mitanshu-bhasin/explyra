## 2025-07-29 - Dynamic ARIA Labels for Stateful Icon-Only Toggles
**Learning:** Icon-only toggle buttons (like password visibility toggles using an eye icon) require not just an initial `aria-label`, but one that dynamically updates to accurately reflect the action the user will take next (e.g., changing from "Show password" to "Hide password"). Relying solely on the changing visual icon class leaves screen reader users without accurate context of the current state or impending action. Additionally, the inner `<i>` tag containing the icon should include `aria-hidden="true"` to prevent screen readers from parsing the icon class itself.
**Action:** When implementing stateful icon-only toggle buttons, always pair the visual state change (e.g., `icon.classList.replace()`) with a corresponding DOM update to the button's `aria-label` and `title` attributes. Ensure the icon element itself is hidden from screen readers using `aria-hidden="true"`.
