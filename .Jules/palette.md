## 2024-05-18 - Added ARIA labels to Theme and Password Toggles\n**Learning:** When making stateful toggles accessible, it is not enough to just add a static `aria-label`. The JavaScript function handling the state change must dynamically update both the `aria-label` and `title` to accurately reflect the element current action/state (e.g., "Hide password" when text is visible, "Show password" when masked). Additionally, decorative icons inside these buttons must be hidden using `aria-hidden="true"` to avoid redundant screen reader announcements.\n**Action:** Ensure all interactive icon-only buttons include an `aria-label`, hide their inner `<i>` tags with `aria-hidden="true"`, and verify that their labels are kept in sync via JavaScript if their state changes.
