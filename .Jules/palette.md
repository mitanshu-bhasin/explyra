## 2024-07-07 - Dynamic ARIA attributes on stateful toggle buttons
**Learning:** For icon-only stateful toggle buttons (like password visibility Show/Hide), a static `aria-label` is insufficient because the state changes upon interaction. Using a visually hidden text fallback without dynamic ARIA labels leaves screen readers without the context of the new state. Also, standard icons (`<i>` tags) inside such buttons are parsed by screen readers unless hidden with `aria-hidden="true"`.
**Action:** When implementing or updating toggle buttons (e.g. `togglePasswordVisibility`), always dynamically update `aria-label` and `title` to reflect the button's current state (e.g., from "Show password" to "Hide password") and always hide child icon elements from screen readers using `aria-hidden="true"`.
